Descrição

Este repositório / projeto contém as 19 questões do trabalho de probabilidade e estatística do professor Pedro Tauã, as questões estão resolvidas de diversas maneiras deste maneira genérica tal como específicas para determinado caso, também utilizei OOP para relembrar e outras funções e bibliotecas.

Requisitos

  • Numpy
  • Live-Server

Numpy para as questões e Live-Server se quiser abrir este HTML em um servidor local, afim de baixar as questões.
